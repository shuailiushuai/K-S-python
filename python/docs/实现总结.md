# K+S模型Python实现总结

## 项目概述

本项目实现了K+S（Keynes+Schumpeter）劳动与金融增强型代理人基模型（ABM）的Python版本。原始模型使用C++在LSD仿真环境中实现，包含约10,800行代码。

## 技术选择：纯Python vs Mesa 3.0

经过详细分析，选择**纯Python实现**而非Mesa 3.0框架，原因如下：

### 选择纯Python的理由

1. **复杂的时序依赖**：模型具有复杂的方程序列和特定的变量计算顺序，由`timeStep`函数强制执行。Mesa的标准调度器难以适应这种复杂性。

2. **自定义随机数生成**：模型使用C++ mt19937_64随机引擎，具有精确的种子要求以确保可重复性。需要直接控制以匹配行为。

3. **存量流量一致性**：模型保持严格的存量流量一致性，具有需要精确时序控制的复杂相互依赖关系。

4. **LSD特定特性**：原始实现使用LSD特定的宏、钩子和数据结构，不直接映射到Mesa框架。

5. **性能优化**：直接Python实现允许在没有框架开销的情况下进行优化。
