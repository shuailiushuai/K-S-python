### 2.1 统计模块增强 / Statistics Module Enhancement

#### 投资统计 / Investment Statistics
- `EId`: 扩张投资需求 / Expansion investment demand
- `SId`: 替代投资需求 / Substitution investment demand
- `RS2`: 期望机器订单 / Desired machine orders

- `w2avgLarg`: 大企业平均工资 / Large firm average wage

#### 质量变化追踪 / Quality Change Tracking
- `q2posChg`, `q2preChg`: 质量正/负变化 / Positive/negative quality changes
- `A2posChg`, `A2preChg`: 生产率正/负变化 / Positive/negative productivity changes
- `w2realPosChg`, `w2realPreChg`: 实际工资正/负变化 / Real wage changes

### 3.1 当前文件结构 / Current File Structure

```
python/model/
├── agent.py              # 基础代理类 / Base agent class

│   ├── CapitalSector       # 资本品部门

└── data_structures.py    # 数据结构 / Data structures (101行)
```

### 3.2 组织原理 / Organization Principles

✅ **模块化分离** / **Modular Separation**
- 每个代理类型独立文件 / Each agent type in separate file
- 清晰的职责分离 / Clear separation of responsibilities

✅ **对应C++结构** / **Mirrors C++ Structure**
- Python文件直接对应C++ .h文件 / Python files map to C++ .h files
- 便于比对和验证 / Easy comparison and verification

✅ **合理的文件大小** / **Reasonable File Sizes**
- 大多数文件200-700行 / Most files 200-700 lines
- `country.py`较大(2014行)但组织良好 / `country.py` larger but well-organized

### 3.3 不建议进一步拆分的原因 / Why Not to Split Further

1. **相关部门紧密耦合** / Sectors are tightly coupled
   - CapitalSector, ConsumptionSector, FinancialSector相互依赖
   - 在同一文件中便于维护

2. **符合ABM最佳实践** / Follows ABM best practices
   - 容器类通常组织在一起
   - 与LSD/C++结构一致

3. **已经具有良好的可读性** / Already highly readable
   - 清晰的类定义和文档
   - 方法组织合理
