# K+S模型Python复现完整说明文档

## 一、项目概述

本项目完成了K+S (Keynes+Schumpeter) 宏观经济Agent-Based Model从C++/LSD到Python的完整复现。

### 1.1 原始模型概述

**K+S模型**是一个存量-流量一致的异质性主体宏观经济模型，结合了：
- **凯恩斯理论**：总需求驱动的经济波动
- **熊彼特理论**：技术创新和创造性破坏

**核心特征：**
- 有限理性的异质性主体
- 内生的技术创新和生产率增长
- 劳动力市场搜寻-匹配机制
- 信贷约束和金融不稳定
- 存量-流量一致性（所有金融流严格追踪）

## 二、实现方案选择

### 2.1 技术选型：纯Python + NumPy vs Mesa 3.0

**最终选择：纯Python + NumPy**

**选择理由：**

✓ **纯Python的优势：**
1. **精确的方程顺序控制**：模型需要严格控制每个时间步内方程的计算顺序，这对存量-流量一致性至关重要
2. **无框架约束**：不受Mesa框架的调度器限制，可以完全按原模型逻辑实现
3. **复杂逻辑直接实现**：避免框架抽象层带来的复杂性
4. **更好的对应关系**：与原C++代码保持更直接的对应关系，便于维护和验证
5. **性能优势**：对于大规模主体，NumPy数组操作比Mesa的对象更高效

✗ **不使用Mesa的原因：**
1. Mesa的标准调度器无法支持所需的精确方程顺序
2. 即使使用Mesa也需要大量定制，失去框架优势
3. Mesa的空间组件在本模型中不需要
4. Mesa的内置可视化不适合时间序列分析
5. 框架开销大于收益

## 三、模型结构

### 3.1 主体类型

模型包含6类主体：

**1. 资本品企业 (Firm1) - 20家初始企业**
- **功能**：研发创新、生产异质性机器、技术竞争
- **核心行为**：
  - 研发：创新(innovation)和模仿(imitation)两种方式
  - 生产：按需生产机器
  - 定价：成本加成定价法
  - 雇佣：根据订单确定劳动力需求

**2. 消费品企业 (Firm2) - 100家初始企业**
- **功能**：生产消费品、管理资本存量、市场竞争
- **核心行为**：
  - 期望形成：自适应需求预期
  - 生产规划：基于预期需求和库存
  - 投资决策：扩张投资和替代投资
  - 可变加成定价：根据市场份额调整加成率

**3. 工人 (Worker) - 1000名初始工人**
- **功能**：求职、工作、消费、技能积累
- **核心行为**：
  - 求职搜寻：向多家企业申请工作
  - 技能积累：机器操作技能(vintage skills)和在职学习技能(tenure skills)
  - 消费决策：用工资和失业救济金消费
  - 退休和新进：人口动态

**4. 银行 (Bank) - 10家银行**
- **功能**：存款吸收、信贷分配、资本充足率管理
- **核心行为**：
  - 吸收存款：来自企业和工人
  - 信贷分配：基于优序融资(pecking order)原则
  - 信用评分：4级信用分类系统
  - 利率结构：基于央行基准利率调整

**5. 机器世代 (Vintage)**
- **概念**：同一时期购买的同质机器组成一个世代
- **属性**：生产率、价格、供应商、使用寿命

**6. 政府和央行**
- **政府**：税收、失业救济、培训、公共债务管理
- **央行**：利率设定(泰勒规则)、银行救助

### 3.2 市场机制

**1. 劳动力市场**
- 分散式搜寻-匹配
- 工人向多家企业投递简历
- 企业提供工资要约
- 不保证市场出清

**2. 商品市场**
- 复制者动态(replicator dynamics)
- 基于竞争力的市场份额演化
- 配给机制（供给<需求时）

**3. 资本品市场**
- 网络化的供应商-客户关系
- 技术扩散通过客户网络
- 机器订购和交付

**4. 金融市场**
- 企业的信贷需求
- 银行的信贷供给（Basel约束）
- 优序融资分配机制

## 五、核心实现细节

### 5.1 时间步顺序

每个时间步严格按照以下顺序执行（确保存量-流量一致性）：

```python
1. 央行更新利率（泰勒规则）
2. 金融市场更新利率结构
3. 消费品企业形成预期、规划生产、确定劳动需求、确定投资需求
4. 资本品企业接收订单、规划生产、确定劳动需求
5. 工人提交求职申请
6. 劳动力市场匹配工人和岗位
7. 企业用实际雇佣劳动力生产
8. 企业设定价格
9. 政府确定支出
10. 工人确定消费需求
11. 商品市场匹配需求和供给
12. 企业计算利润并纳税
13. 银行计算利润并纳税
14. 政府收税、更新公共债务
15. 计算宏观总量
16. 处理企业进入退出
17. 银行更新信用评分
```

### 5.2 关键参数（200+个参数）

**生产和技术：**
- `nu=0.04`: 研发强度（收入的比例）
- `xi=0.5`: 创新vs模仿的分配
- `zeta1=0.3, zeta2=0.3`: 研发成功弹性
- `m1=1.0`: 资本品部门劳动生产率
- `m2=1.0`: 机器生产率
- `b=20`: 机器回报期
- `eta=20`: 机器技术寿命

**市场动态：**
- `chi=1.0`: 竞争力选择性参数
- `gamma=0.5`: 客户网络参数
- `omega1=1.0, omega2=1.0, omega3=0.0`: 竞争力权重（价格、交付、质量）
- `upsilon=0.02`: 加成率调整速度

**劳动力市场：**
- `omega=1.0`: 在职工人求职申请数
- `omegaU=3.0`: 失业工人求职申请数
- `phi=0.5`: 失业救济率
- `theta=0.0`: 雇佣时的松弛度
- `psi1-psi6`: 工资决定参数
- `tauT=0.01`: 在职学习率
- `tauU=0.01`: 技能衰减率

**金融系统：**
- `Lambda=10.0`: 信贷倍数
- `tauB=0.08`: 银行资本充足率
- `muD=0.5, muDeb=0.5, muRes=0.9`: 利率息差

**政府和政策：**
- `tr=0.1`: 税率
- `rT=0.03`: 目标利率
- `gammaPi=1.5, gammaU=0.5`: 泰勒规则权重

## 六、使用方法

### 6.1 安装

```bash
cd python
pip install -r requirements.txt
```

### 6.2 基本运行

```python
from ks_model import KSModel

# 创建模型
model = KSModel(seed=42)

# 运行模拟
model.run(time_steps=500)

# 获取结果
stats = model.get_statistics()
print(f"最终GDP: {stats['GDP_real'][-1]}")
print(f"最终失业率: {stats['unemployment_rate'][-1]*100:.1f}%")

# 保存结果
model.save_results("results.csv")

# 绘图
model.plot_results()
```

### 6.3 自定义配置

```python
# 使用配置文件
model = KSModel(config_file="config/my_config.json", seed=42)
model.run(time_steps=1000)
```

### 6.4 制度变迁实验

```python
model = KSModel(seed=42)
model.params.set('TregChg', 200)  # 在t=200时制度变迁
model.params.set('trChg', 0.15)   # 变迁后更高的税率
model.run(time_steps=500)
```

## 十一、常见问题

**Q1: GDP为什么是0？**
A: 模型需要初始化期让生产启动。前几步的值可能为0，需要运行50-100步后观察。

**Q2: 如何加速模拟？**
A: 可以考虑：
- 减少主体数量（工人、企业）
- 使用Numba编译关键函数
- 减少统计收集频率

**Q3: 如何复现论文结果？**
A: 
1. 使用论文对应的配置文件
2. 运行足够多的蒙特卡洛实验（20+）
3. 比较统计矩而非具体数值
4. 考虑使用C++版本做精确复现

**Q4: 如何扩展模型？**
A: 模块化设计便于扩展：
- 修改主体行为：编辑`agents/`目录下的类
- 修改市场机制：编辑`markets/`目录下的类
- 添加新变量：更新`utils/statistics.py`
