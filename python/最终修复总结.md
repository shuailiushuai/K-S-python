### 2. ✅ Firm1负产出Bug

**问题描述**：
- 当R&D工人超过总工人时，生产工人变为负数
- 导致产出为负（例如期间1产出-1095）
- 原因：`production_workers = labor_actual - rd_workers`可能小于0

**C++参考**：
- `fun_KS_firm1.h`第440行：`RESULT(max(v[0], 0))`确保产出非负
- 复杂的分配逻辑防止R&D消耗所有工人

**修复方案**：
```python
# 使用部门分配的rd_workers和production_workers
# 这些值由allocate_sector1_rd_labor()设置
max_output = self.production_workers * self.labor_productivity_output * m1
self.output = max(0, min(self.output, max_output))
```

**文件**：`python/agents/firm1.py`

### 3. ✅ 初始劳动力分配错误

**问题描述**：
- 初始劳动力分配使用任意公式：`labor_per_firm1 = (total_workers - labor_firm2) / F1`
- 未使用正确计算的Ld10和Ld20值
- Firm1每个企业只分配~10个工人，实际需要~37个

**C++参考**：
- `fun_KS_country.h`第489-490行：
  * `Ld10 = RD0 / INIWAGE + D10 / (Btau0 * m1)` = 742工人
  * `Ld20 = D20 / INIPROD` = 839工人

**修复方案**：
```python
# 使用正确计算的劳动力需求
self.params.set('Ld10', Ld10)  # 总计：742工人
self.params.set('Ld20', Ld20)  # 总计：839工人

# 用于雇佣分配
labor_per_firm1 = Ld10 / F1  # 742 / 20 = 37.1 工人/企业
```

**文件**：`python/ks_model.py`

**注意**：总劳动力需求（1581）超过供给（1000）。这是**正确的** - C++模型中劳动力市场自然处理短缺。

### 4. ✅ Firm1初始收入过高

**问题描述**：
- 初始化设置`revenue = 2000.00`（占位符值）
- 导致R&D支出 = nu * revenue = 0.04 * 2000 = 80
- 每个企业需要80个R&D工人，总计1600工人需求！

**正确计算**：
- 基于初始机器需求D10 = 37台（总计）
- 每个企业：D10/F1 = 37/20 = 1.85台
- 初始收入 = 1.85 * p10 = 1.85 * 20 = 37

**修复方案**：
```python
# 计算正确的初始销售
initial_sales = D10 / F10  # 公平分配初始需求
initial_revenue = initial_sales * p10
firm.revenue = initial_revenue
# 填充销售历史，以便R&D使用正确的过去销售
firm.sales_history = [initial_sales]
```

**文件**：`python/ks_model.py`

**影响**：R&D劳动力需求从1600降至~30，合理！

### 5. ✅ Firm2初始劳动力需求不一致

**问题描述**：
- 初始化设置`labor_demand = Ld20/F2 = 10.25`每个企业
- 但第1期规划运行时：
  * `output_planned = capacity * u = 8.0 * 0.75 = 6.0`
  * `labor_demand = output_planned / productivity = 6.0`
- 由于theta=0.0，企业立即解雇多余工人：10 - 6 = 4工人/企业
- 总计：第1期解雇400+工人

**根本原因**：
初始化公式（假设满负荷）与实际规划（使用u=0.75利用率）不一致。

**修复方案**：
```python
# 关键修复：设置初始labor_demand与u利用率的计划产出一致
# 这防止第1期大规模解雇
# Labor demand = output_planned / productivity
firm.labor_demand = firm.output_planned / INIPROD
```

**文件**：`python/ks_model.py`

**影响**：Firm2从600工人开始（匹配需求），而不是1000工人，避免第1期大规模解雇。
