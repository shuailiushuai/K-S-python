# 现金流实现 - 完整文档

## 概述

本文档描述了 Python K+S 模型中 `cash_flow()` 函数及相关财务管理函数的完整实现，与 C++ 实现（`fun_KS_support.h:169-221`）完全匹配。

## 问题描述

原 Python 实现存在**高优先级缺口**：`cash_flow()` 函数被简化，仅包含基本的利润/税收/股息计算，但缺少完整的存款/债务动态。这限制了：
- 金融稳定性分析
- 危机检测
- 企业破产处理
- 完整的存量-流量一致性

### 1. `support.py` 中的核心函数

实现 C++ 的 `update_debt()` 函数（fun_KS_support.h:105-137）。

**功能：**

**关键特性：**

#### `update_depo(firm, depo: float, incr: bool) -> float`

实现 C++ 的 `update_depo()` 函数（fun_KS_support.h:142-159）。

**功能：**
- 更新企业净值（`_NW1`/`_NW2`），代表银行存款
- 支持增量变化（incr=True）和绝对设置（incr=False）

**关键特性：**
- 灵活的存款管理（增量或设置）
- 正确处理零变化
- 与 C++ 实现直接对应

#### `cash_flow(firm, profit: float, tax: float) -> float`

实现完整的 C++ `cash_flow()` 函数（fun_KS_support.h:169-221）。

**功能：**

1. **计算自由现金流：**
   ```
   cashFree = 利润 - 税收 - 奖金 - 上期股息
   ```

2. **处理亏损（负现金流）：**
   - 如果存款 ≥ |亏损|：从存款中提取
   - 如果存款 < |亏损|：
     - 借款弥补差额
     - 如果有信贷：将存款设为 0
     - 如果无信贷：将存款设为 -1e-6（破产信号）

3. **处理盈利（正现金流）：**
   - 计算期望债务偿还：`债务 * deltaB`
   - 如果现金 > 期望偿还：
     - 偿还期望金额
     - 存入剩余部分
   - 如果现金 < 期望偿还：
     - 偿还所有可用现金
   - 如果无债务：存入所有现金

**关键特性：**
- 完整的财务周期管理
- 显式破产检测（负净值）
- 可配置利率的债务偿还（deltaB）
- 适当的财务操作顺序
- 使用滞后股息（上期）

### 2. 企业级方法

#### Firm1 和 Firm2: `compute_tax_and_cash_flow(tr: float) -> float`

实现 C++ 的 `_Tax1` 和 `_Tax2` 方程。

**功能：**
- 计算利润税（亏损不征税）
- 调用 `cash_flow()` 进行完整的财务管理
- 更新：`_Tax1`/`_Tax2`、`_NW1`/`_NW2`、`_Deb1`/`_Deb2`、`_CD1`/`_CD2`、`_CD1c`/`_CD2c`、`_CS1`/`_CS2`

#### Firm1 和 Firm2: `compute_dividends(d1/d2: float) -> float`

实现 C++ 的 `_Div1` 和 `_Div2` 方程。

**功能：**
- 从税后利润计算股息
- 公式：`max(d * (利润 - 税收 - 奖金), 0)`
- 默认支付率：50%（d=0.5）
